# Авито: первый безопасный браузерный оператор — 06.11.2026

## Официальное разрешение и границы

Поддержка Авито 06.11.2026 в 08:07 мск в тикете 79397429 письменно разрешила автоматизацию для редактирования собственных альбомов портфолио и публичного профиля. При этом 05.11 поддержка сообщила, что API для этих действий отсутствует. По словам поддержки, сотруднику компании можно делегировать объявления и портфолио внутри них; публичные сведения профиля изменяет только владелец.

Это разрешение не охватывает обход CAPTCHA, антибот-защиты, 2FA, передачу пароля, переписку с покупателями или финансовые действия.

## Фактически реализовано в ветке

1. tools/avito_browser_operator.py — локальный обычный Chromium через Playwright в графическом режиме. Он не вводит пароль и не пытается обойти вход. Авторизация остаётся на устройстве владельца.
2. inspect — только осмотр страницы и создание приватного локального скриншота. Владелец сам входит и открывает нужный раздел.
3. check-plan — офлайн-проверка фиксированного JSON-плана; не требует подключения к Авито.
4. apply-plan — действия только над подтверждёнными, однозначно найденными элементами интерфейса: ввод текста, выбор кнопки и загрузка изображения. Перед выполнением требует ввода точного слова ПРИМЕНИТЬ на локальном компьютере. Запрещены сообщения, платежи, изменение безопасности, произвольный JavaScript.
5. tests/test_avito_browser_operator.py — 18 офлайн-проверок безопасности. Новый CI workflow запускает только тесты, никогда браузер, никаких ключей и профиля.

Это лишь техническая заготовка, а НЕ уже полученный доступ. Реальные элементы и их подписи в интерфейсе Авито ещё не проверены; сохранение профиля вживую не проводилось. Скрипт не является автономным оператором до живого испытания.

## Как испытать локально

Только на компьютере владельца, Python 3.10+:

    python -m pip install playwright
    python -m playwright install chromium
    python tools/avito_browser_operator.py inspect

Откроется Chromium; владелец самостоятельно авторизуется, при необходимости проходит обычный CAPTCHA или 2FA, открывает портфолио либо настройки публичного профиля и нажимает Enter в терминале. Файл снимка останется локально в домашней папке пользователя (~/.local/share/avito-browser-operator/). Не загружать туда секреты. НЕ передавать папку авторизации и скриншоты в публичный GitHub/Drive.

## Пример офлайн-плана (только шаблон — названия полей НЕ подтверждены)

    {
      "purpose": "public-profile",
      "steps": [
        {"action": "fill", "by": "label", "name": "Описание профиля", "value": "Проверенное описание нашей ИИ-экосистемы"},
        {"action": "click", "by": "role", "name": "Сохранить"}
      ]
    }

Сохранить JSON-файл ТОЛЬКО локально, затем проверить: python tools/avito_browser_operator.py check-plan LOCAL_PLAN.json

После живой проверки нужных названий и отдельного разрешённого теста можно выполнить локально: python tools/avito_browser_operator.py apply-plan LOCAL_PLAN.json

Действие требует ввести ПРИМЕНИТЬ, не должно выполняться в CI. Если страница, домен или названия полей меняются — остановка, никакого угадывания. Частично выполненные действия автоматически НЕ откатываются; результат требуется проверять в публичной карточке отдельно. Кнопка «Сохранить» может отсутствовать или иметь другое имя — ни один селектор пока не подтверждён.
