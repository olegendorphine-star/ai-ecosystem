## Минимальная программа проверки

**Шаг 1 — выполнен, стоимость 0 ₽:** чтение данных, предварительная проверка, расчёт цены, проверка кошелька, получение статистики. Подтверждение: зелёный workflow `Avito minimum promotion safe DRY RUN (zero spend)`, job 127132223142. Команду безопасно повторять из GitHub Actions через `workflow_dispatch`; всё ещё **ни один API вызов покупки** не производится.

**Шаг 2 — требует отдельного согласования, верхний предел 545 ₽:** испытать **одну** самостоятельную услугу — предпочтительно XL для Москвы, так как у неё больше визуального эффекта, чем у выделения цветом, при той же цене. Не брать значки, вторую услугу, пакеты увеличения просмотров, рекламу Петербурга или автопродление в рамках первого теста. Перед покупкой перепроверить live price=545 ₽, `active` и `wallet real>=545`, отсутствие уже активного XL, а также разрешения интеграции. Если цена изменилась или средств недостаточно — STOP. Если есть автопродление, не активировать его. **Одна авторизованная покупка через API — только после явного согласия владельца на XL за сумму до 545 ₽.** Для оплаты может потребоваться пополнение кошелька самим владельцем. Не раскрывать финансовые данные в публичные логи.

**Шаг 3 — без дополнительных покупок:** читать статус применённого продвижения после подтверждения API, проверить актуальный расход через историю операций и статистику. Собрать показатели контактов/просмотров до и после, оценить результат по реальным обращениям и стоимости обращения, а не по просмотрам. По окончании срока убедиться, что автопродления не было.

**Шаг 4:** Санкт-Петербург только после подтверждения его `active` и присвоения настоящего AvitoId. Запросить индивидуальные цены заново; не считать московские 545 ₽ автоматически петербургской ценой. Для первого платного теста город Москва.

## Обязательные ограничения

- Никакой скрытой или фоновой автоматической покупки без согласованного тарифа и лимита.
- `ListingFee=Package` и `AdStatus=Free` в XML **не эквивалентны** запрету на платный `PUT`: все мутационные методы платного продвижения должны быть отдельными, с явным разрешением и максимальной ценой.
- Расход 0 ₽ в DRY RUN проверен по отсутствию мутационных запросов; точный баланс и финансовые реквизиты не публикуются в GitHub.
- Все результаты и следующие решения записывать в главный паспорт проекта на Google Диске, отдельно от Gii.
