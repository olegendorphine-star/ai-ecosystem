## 4. Ошибки ассистента и что запрещено повторять

1. Вместо исполнения «опубликуй сама» пользователь получал обсуждения, планы, ZIP и ссылки — это не выполнение цели.
2. Вместо вывода полного текста и шести изображений непосредственно в чат ассистент показывал архивы и даже поисковую иллюстрацию, не являющуюся рекламным оригиналом. Название файла не доказывает соответствие содержимого; пользователь прямо сказал «Фото не те».
3. Отождествлялись «GitHub Actions success», HTTP 200, исторический `last_successful` и публикация сейчас; это некорректно.
4. В готовый XML были внесены ошибки `Id` и `Category` без проверки по последнему успешному формату; результатом были 1013/1008 и снятие предыдущей версии.
5. Изображения ссылались на Google Диск вопреки запрету пользователя и без проверки `Content-Type=image/...`; Авито вернул 1316.
6. Повторные попытки без достаточной проверки состояния приводили к скриптовому `JSONDecodeError` на пустом HTTP 200 и затем к HTTP 429.
7. Не различались границы обычного чата, GitHub и Work с браузером. Нельзя обещать реальное управление без проверенного инструмента.
8. Нельзя заявлять, что «готовый пакет» равнозначен «загруженным фото» или что user-approved текст подтверждает user-approved визуальную версию.

## 5. Блокеры и операционное решение

- **Главный блокер:** нет проверенного механизма передачи именно ШЕСТИ утверждённых бинарных изображений на доступные Авито фото-URL или в UI личного кабинета. Прямая загрузка из текущего обычного чата не подтверждена. Рабочие варианты — авторизованное управление браузером Work (если доступно на практике) либо прямой публичный HTTPS-хостинг файлов под контролем проекта, с проверкой каждого image GET 200, Content-Type и байтов, без Google Drive, с последующим применением верного XML.
- Перед новой записью: проверить визуальные исходники; сохранить неизменными существующий Id/AvitoId, категорию, Price 5000/Free; полный набор полей услуги; убедиться, что фид не создаст дубль и не вызовет `removed_from_file`; соблюсти ограничения API после 429.
- Новый controlled upload допустим **только после** устранения неработающих фото-ссылок и валидации XML. Не загружать снова заведомо ошибочную версию.
- Приёмка: свежий `active` для внешнего ID 8347570435; верный текст, цена и 6 оригинальных фото; нет дубля и платного продвижения; доказательство по актуальному `current/items` и непосредственному чтению карточки. До этого статус задачи: **НЕ ВЫПОЛНЕНО**.
