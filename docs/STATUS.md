Дата подготовки стартовой структуры: 2026-11-04.

## Подтверждено

- Владелец проекта выбрал раздельное ведение Gii и коммерческой ИИ-экосистемы.
- GitHub-аккаунт для репозиториев: `olegendorphine-star`.
- Для коммерческого проекта создан отдельный **приватный** репозиторий `olegendorphine-star/ai-ecosystem`; существование и приватность подтверждены через подключённый GitHub.
- Авторизованное подключение ChatGPT к этому репозиторию подтверждено: доступны операции чтения и записи; это не подтверждает отдельные доступы Kimi и Codex.
- В `main` сохранены стартовые `README.md`, `AGENTS.md`, `.gitignore`, `.env.example`, `docs/AVITO_API_PLAN.md`, `docs/STATUS.md`; все файлы проверены чтением обратно из GitHub. Работающего кода API Авито нет.

Запрос к API rulesets вернул 403: для этого приватного репозитория GitHub предлагает GitHub Pro или публичность. Правила `AGENTS.md` сами по себе не блокируют прямой push. Не давать неограниченные права записи непроверенным исполнителям.
- Наличие и объём разрешений API Авито, параметры авторизации, тарифные/правовые условия.
- Готовность действующего API-клиента, автоматизации, ИИ-агентов и сервера.
- Подключение OpenAI API, его биллинг и доступность конкретных моделей.
- Какие-либо действия через Avito API.

## Условия приёмки первой технической версии

1. Приватный репозиторий существует и доступен уполномоченным участникам.
2. Защита `main` настроена или явно документировано, что её пока нет.
3. Код и тесты разрабатываются в отдельных ветках, без секретов.
4. Согласован точный список API-действий и разрешений, которые выдаст Авито.
5. Проверены mock-тесты, безопасная повторяемость и журналирование.
6. Первый живой запрос или публикация требуют отдельного разрешения владельца.

Создание приватного репозитория и доступ подключённого ChatGPT подтверждены отдельно. Остальные условия требуют проверки по факту, а не по плану.
