# Freelancehunt API — начальный read-only коннектор

Статус: код подготовлен для проверки. **Реальное соединение не подтверждено.** Ранее присланный в чат токен считать скомпрометированным — отозвать его. Никогда не сохранять токен в репозиторий, переписку, Issues или логи.

## Подключение

1. В Freelancehunt → «Приложения и API» отозвать старый токен и выпустить новый.
2. В GitHub → Settings → Secrets and variables → Actions → New repository secret создать `FREELANCEHUNT_API_TOKEN`, вставив **новый** токен напрямую в защищённое поле GitHub. Не размещать его в чате.
3. После принятия PR вручную запустить workflow «Freelancehunt - API connectivity (read-only)» в Actions.
4. Проверить результат `connected_read_only`. Скрипт проверяет авторизацию через GET /v2/my/profile и видимость проектов через GET /v2/projects; он не пишет персональные поля в логи.

## Безопасность

- Никаких POST/PATCH/DELETE и автоматических откликов. Здесь только read-only тест подключения.
- HTTP-ошибки выводятся только кодом (`http_401`, `http_403` и т. п.), без ответа сервера, токенов, имени и ID пользователя.
- Данные проектов не сохраняются; выводится только количество на первой странице.
- Условия дальнейших откликов, профиля и верификации проверяются отдельно.
- API: https://apidocs.freelancehunt.com/

## Приёмка

Офлайн-тесты `python -m unittest tests/test_freelancehunt_probe.py`; затем отдельно workflow с безопасным секретом. Пока workflow не выполнен успешно, не заявлять о подключении Freelancehunt или готовности автооткликов.
