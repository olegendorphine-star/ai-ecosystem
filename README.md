# ИИ-экосистема — коммерческий проект

Этот приватный репозиторий предназначен для разработки коммерческой ИИ-экосистемы, в том числе будущей интеграции с API Авито. **Это отдельный проект от Gii** (`olegendorphine-star/gii-experiments`). Не переносить сюда код, исследовательские данные и протоколы Gii без отдельного решения владельца.

## Текущий статус

- Структура репозитория подготовлена; работающий клиент API Авито пока не добавлен.
- Авторизация, доступ к API, клиентские ключи, токены, тарификация и запуск интеграции **не подтверждены**.
- Развёртывание на сервере и публикация объявлений **не выполнялись**.
- Источником истины по внешним доступам остаются ответы Авито и условия выданного API-доступа.

## Договорённости по разработке

- `main` — только проверенный и принятый код. Разработчики работают в отдельных ветках и создают Pull Request.
- Сначала офлайн-тесты и ревизия, затем ограниченные sandbox/тестовые проверки, далее — только отдельно согласованные живые операции.
- Не публиковать объявления, не отправлять сообщения от аккаунта и не инициировать платные действия без явного разрешения владельца.
- API-ключи, OAuth-токены, секреты, персональные данные и реальные ответы пользователей не включать в Git.
- Сверяться с [AGENTS.md](AGENTS.md), [docs/STATUS.md](docs/STATUS.md) и [docs/AVITO_API_PLAN.md](docs/AVITO_API_PLAN.md).

## Предлагаемая структура после согласования API

- `src/avito/` — клиент API, авторизация и контролируемые методы.
- `src/agents/` — ИИ-модули экосистемы.
- `tests/` — офлайн-тесты на имитациях ответов.
- `docs/` — решения, протоколы интеграции и контроль доступа.

Папки с кодом добавлять по мере готовности, а не создавать имитацию уже работающей системы.
