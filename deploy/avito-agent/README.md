# Изолированный Avito worker на VPS

Этот контур предназначен для read-only проверки сервера перед подключением браузера.
Он не заменяет Gii и не должен использовать его systemd unit, базу, порт,
каталоги или браузерный профиль.

## Размещение

Использовать отдельного системного пользователя и каталог:

```text
/srv/ai-ecosystem/avito-agent/
```

Файлы worker-а устанавливаются владельцем сервера из проверенного PR. Профиль
браузера, если он будет добавлен позднее, хранится только в отдельном зашифрованном
volume этого контура.

## Ограничения

- максимум 1 CPU и 1536 MiB RAM для первого запуска;
- один worker и один браузерный профиль;
- отдельный порт, если он понадобится;
- без `privileged`, host network и доступа к каталогам Gii;
- сначала только `health`, `browser_health`, `connect_status`;
- write-действия и платежи выключены.

## Порядок приёмки

1. Сделать резервную копию конфигурации и проверить активность сервисов Gii.
2. Установить worker в отдельный каталог.
3. Выполнить три read-only действия локально.
4. Сравнить CPU/RAM/диск и состояние Gii до и после.
5. Запустить GitHub Actions probe через SSH с pinned `known_hosts`.
6. Только после успешного probe добавлять Chromium/Playwright и ручную авторизацию.

Секреты, cookies, OTP и SSH-ключи не хранятся в GitHub, Google Drive или логах.
